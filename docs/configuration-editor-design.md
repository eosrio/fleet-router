# Configuration editor

Visitor mode: Operate. Extend the existing dashboard with authenticated file reload and JSON editing. Preserve its navigation, typography, tokens and controls.

## Direction contract

THESIS: Operators can inspect the exact file, validate a draft, and apply it while understanding which existing streams are draining.

OWN-WORLD: Inherit the dashboard's flat surfaces, hairline rows, mono configuration text, teal success and amber warning states.

STORY: Unlock controls; load the configured file; edit JSON or reload an external edit; validate and apply; see the new revision and retained streams in pushed state.

FIRST VIEWPORT: The existing masthead remains. Configuration title and file path precede a compact action row, a full-width labelled JSON editor and inline feedback. Pending drains appear below the editor as rows. The main action is Save and apply.

FORM: Extension of the existing operational dashboard, using its established form and action conventions. No concept roll applies to this scoped extension.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

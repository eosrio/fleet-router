One WebSocket for the whole SHiP fleet.

fleet-router is a Rust reverse proxy and load balancer for Antelope State History nodes. Hyperion, Atomic, and other indexers open a single connection. The router picks a healthy upstream and keeps that connection up when a node drops.

What it does

01 — Features

Single resilient endpoint

Hyperion, Atomic, and other indexers share one WebSocket instead of pinning each consumer to a single SHiP node.

Range-aware least-connections

Prefer an upstream whose trace range covers the requested block, then the least-loaded healthy node. A get_blocks_request_v1 with fetch_finality_data is sent only to an upstream whose finality range covers that block.

Transparent failover

If the active upstream drops, the client socket stays open. fleet-router resumes get_blocks at the next block, de-duplicates blocks already delivered, and replays client frames buffered during the swap.

Many networks, one process

listeners serves each chain on its own port, with its own upstream pool, chain_id, connection cap, and /ready/<name> check.

chain_id verification

An upstream whose reported chain_id disagrees with the pin or the rest of its pool stays offline. Nodes that omit chain_id — FIO and other EOSIO 2.0 builds — stay usable unless require_chain_id is set.

Bounded failover and quarantine

Repeated unclean drops at the same next block are bounded: the session closes with WebSocket code 1011 after five. Opt-in block_failure_quarantine skips a corrupted SHiP log range without marking the node offline.

Prometheus metrics

Per-upstream series carry server and endpoint labels, plus listener in multi-listener mode, including SHiP range gauges for trace, chain state, and finality.

Upstream wss://

Optional TLS to SHiP nodes. Certificates are verified with rustls against the OS trust store. A bare host:port stays ws://. The client listener remains plaintext.

Graceful shutdown

Handles SIGINT and SIGTERM with a bounded drain and WebSocket close frames. Written in Rust on tokio and tokio-tungstenite. ABI checks use pure-Rust rs_abieos, so libclang is not required.

How a request moves

02 — Architecture

  1. Client connects over WebSocket. The router forwards the selected upstream's ABI.
  2. Selection prefers a trace range that covers the block, then the least-loaded healthy upstream.
  3. On loss, get_blocks resumes at the next block on another suitable node.
  4. Replayed blocks the client already has are dropped. The client does not reconnect.

Unclean drops at the same next block back off and stop after five, closing the client with code 1011. Quarantine is off until block_failure_quarantine is set. The bound itself is always on.

Install

03 — Run it

crates.io

Requires Rust 1.99 or newer. Building wss:// support needs a C compiler and CMake; they are not required at runtime.

shell 
cargo install fleet-router

Docker

Image ghcr.io/eosrio/fleet-router on GHCR, published on tagged releases. It runs as a non-root user.

shell 
docker pull ghcr.io/eosrio/fleet-router

Prebuilt binaries

GitHub Releases ships archives for these targets. Download a release.

  • Linux x86_64
  • macOS arm64
  • macOS x86_64
  • Windows x86_64

Quick start

  1. shell 
    fleet-router config init ./config.json
  2. shell 
    fleet-router config test ./config.json
  3. shell 
    fleet-router run --config ./config.json

Do not expose fleet-router directly to the public internet. The client listener is plaintext ws:// and unauthenticated. Terminate TLS and add access control on a reverse proxy in front of it.

Multi-listener config

  "upstream_status_ms": 5000,

      "name": "eos",
      "listen_port": 17000,

Health and metrics

05 — Observe

/health
200 while the process is running.
/ready
200 when every listener has an online upstream. In single-port mode, when at least one upstream is online. Otherwise 503.
/ready/<name>
200 or 503 for that listener, or 404 if the name is unknown.
/metrics
Prometheus text. Set metrics_port to enable the HTTP endpoint.

Labels and range gauges

Each per-upstream series carries server and endpoint. Multi-listener mode adds listener. Range gauges report the start and end block of each SHiP range: trace, chain state, and finality. v0.5.0 also exports block-failure and quarantine gauges. fleet_router_up is a process gauge with no labels.

Logging is tracing, controlled with RUST_LOG (default info).
